Rewind the Finds

A preserved storefront and engineering case study by Jared Hall.

Try the original shopping experience

Browse the archived catalog, filter by category and availability, sort by price or name, open product details, and add items to a persistent cart. Quantity controls, removal, totals, and checkout preview run entirely in your browser.

Browse the catalog →

The systems behind the store

Jared built the customer-facing website and Shopify shopping integration alongside Python tooling for product data, image-assisted product information, market research, and data presentation. Admin tooling imported product data in batches and provided a UI for availability labels and configuration.

The original storefront source uses HTML/CSS, plain JavaScript, and a PHP page shell. The separate backend and admin work used Python. This archive runs the storefront as static HTML and JavaScript; it does not run Python services, AI calls, admin tools, or live Shopify checkout.

Archive details

The repository snapshot contains 170 product records: 148 In Stock and 22 Archived. Labels and prices describe the saved catalog, not current inventory or offers. Product photos are bundled locally where available; missing historical photos use a clearly labeled placeholder. Category illustrations were recreated for the archive.
